# Movie Insight Dashboard

## Project Overview
I built this Python project for my AIM 103 course at Farmingdale State College. It analyzes a dataset of 30 movies to help users explore movie ratings, budgets, and revenue through a simple interactive menu.

## Technologies Used
- Python
- Pandas for loading, filtering, and analyzing movie data
- Matplotlib and Seaborn for creating data visualizations
- CSV files for storing and exporting data

## Features
1. View movie statistics, including average rating, average budget, and the highest-rated movie.
2. Filter movies based on a minimum rating.
3. Generate charts to visualize movie data, including budget versus revenue.
4. Export filtered movie results to a new CSV file.
5. Exit the program.

## How to Run
1. Download `movie_dashboard.py` and `movies.csv` into the same folder.
2. Install the required libraries: `pip install pandas matplotlib seaborn`
3. Run the program: `python movie_dashboard.py`
4. Select an option from the menu.

## What I Learned
This project helped me practice using Python for data analysis, working with datasets, building interactive programs, creating visualizations, and exporting results.
